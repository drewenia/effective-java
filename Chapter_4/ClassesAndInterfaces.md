# Classes and Interfaces

Java programlama dilinin kalbinde class'lar ve interface'ler yer alır. Bunlar, Java'nın basit abstraction unit'leridir.
Dil, class ve interface'leri tasarlarken kullanabileceğiniz birçok güçlü öğe sunar. Bu bölüm, class ve
interface'lerinizi kullanılabilir, sağlam ve esnek hale getirmek için bu öğeleri en iyi şekilde kullanmanıza yardımcı
olacak yönergeler içerir.
